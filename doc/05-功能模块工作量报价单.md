## 1. 报价范围与依据

报价对象为 QA Mini **从零构建到上线**的完整功能范围：接收 asr-tool 推送语音识别文本、
四协议（openai / dify / generic / ragflow）问答、多会话隔离、多浏览器 SSE 实时流式
展示、访问控制、PWA 移动端、测试与 docker 部署。

工作量以本仓库已交付代码的**功能复杂度**为基准反推（行数为 `wc -l` 口径，含空行与注释）：

| 代码分区 | 文件 | 规模 |
|---|---|---|
| 后端 | server.js / lib/config.js / lib/qa_runner.js / lib/sse.js / lib/protocols/ 四协议 | 约 2191 行 |
| 前端 | public/app.js / index.html / style.css / icons.svg / sw.js / manifest | 约 2724 行 |
| 测试 | tests/run_tests.js / mock_backends.js / e2e_local.js | 约 1442 行 |

功能清单与本文档第 3 节 15 个模块一一对应；协议行为口径与 asr-tool 1:1 对齐
（超时 10s 连接 / 60s 块间空闲、统一错误语义），该对齐成本已计入第 5 模块。

## 7. 假设与排除项

1. 需求以本仓库 doc/ 四份文档 + README 描述的功能口径为准；超出第 3 节清单
   的新功能按变更流程评估（单价沿用第 2 节）。
2. 第三方问答服务（RAGFlow / Dify / OpenAI 兼容 / 通用后端）由甲方提供可用
   实例与 API Key；对接联调时间已含在模块 5、13 内，不含后端自身排障。
3. asr-tool 使用对方 dev 分支推送模式现状接口；若 asr-tool 接口变更导致
   重新对接，超出模块 6 范围另计。
4. 服务器（172.16.30.101）由甲方提供并保证可达；硬件/网络故障不在范围内。
5. 本报价不含：反向代理/CDN 配置、公网 TLS 证书、数据迁移（旧系统非
   sessions.json 形态）、培训超过 1 次（1 次 ≤2h 已含在模块 15）。
6. 交付物为源码仓库 + 文档 + 运行容器；不含源码买断/知识产权转让条款
   （如需要另议）。
